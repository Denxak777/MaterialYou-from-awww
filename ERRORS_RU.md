**Список кодов ошибок и решение для "MaterialYou-from-awww"**

Если программа закрылась не закончив свою задачю и выдала ***"Ознакомьтесь с информацией на GitHub или в файле ERRORS_RU.md, чтобы устранить неполадки в программе"***, значит на каком-то моменте произошла ошибка. Найдите свою ошибку ниже и попробуйте решения для востановление программы

========================================================================================

**ERROR-000**

* Причина: Программа awww не работает корректно
* Решение:
    1. Проверте, установлена ли программа ```awww```
    2. Проверте, не установили вы случайно старую версию ```swww``` (Она уже не актуальна разработчиками и не поддерживается моей программой)
    3. Убедитесь, что awww-daemon запущен и работает на вашем ПК
    4. Попробуйте вручную выполнить команду в терменале ```awww query``` и убедитесь, что команда выдала информацию

**ERROR-001**

* Причина: Pywal не смог создать цветовую схему для дальнейшего использования
* Решение:
    1. Проверте, установлена программа ```pywal``` 
    2. Запускается ли ```pywal``` через консоль, для этого ведите wal и получите ответ об использования программы а не ошибку

**ERROR-002**

* Причина: Скрипт не смог найти файлы чтобы забрать конфиги
* Решение: 
    1. Проверте расположение есть ли папка по пути ```~/.cache/wal/```, если там ничего нету то попробуйте найти куда идет сохранение или напишите мне будем решать проблему
    2. Если расположение конфигов находится не в стандартном месте, то в коде поменяйте ```cache_wal_dir = Path.home() / ".cache" / "wal"``` на ваше расположение

**ERROR-003**

* Причина:Скрипт зашел в папку конкретного монитора (например, ./DP-1/), но не обнаружил там файл colors-vscode.json, который должен был скопироваться туда из кэша ```pywal```
* Решение:
    1. Убедитесь, что шаг генерации палитры через Material_You() успешно завершился без ошибок ERROR-001 или ERROR-002
    2. Проверьте, создались ли папки с именами мониторов в корне проекта и лежит ли внутри них файл colors-vscode.json


**ERROR-004**

* Причина: Файл ```colors-vscode.json``` существует, но Python не смог его прочитать
* Решение:
    1. Откройте поврежденный файл в текстовом редакторе и проверьте его структуру
    2. Убедитесь, что используемая вами версия ```pywal``` корректно генерирует шаблоны и не записывает туда пустой массив при сбое генерации палитры из слишком темных/однотонных обоев

**ERROR-005**

* Причина: Python не смог создать цепочку папок по пути ~/.vscode/extensions/materialyou_[имя_монитора]/themes/
* Решение: 
    1. Проверьте права доступа к директории .vscode в вашем домашнем каталоге (запустите ```ls -la ~/.vscode``` и убедитесь, что у вашего пользователя есть права на запись)

**ERROR-006**

* Причина: Не удалось записать финальные файлы манифеста package.json или самой темы theme.json на диск, хотя папки под них были успешно созданы
* Решение:
    1. Проверьте, не переполнен ли системный диск
    2. Убедитесь, что файлы не заблокированы сторонним процессом (например, если в этот момент VS Code активно пытается перезагрузить тему и залочил доступ к файлам расширения)
